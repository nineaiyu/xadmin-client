## 使用说明

- 本清单的「建议取值」是**工程侧建议**，不是产品决议；每项的验证证据都可独立复查；
- 拍板「维持现值」的项：无需任何动作（表格留档即为结论）；
- 拍板「切换」的项：按「一行切换」操作，切换后按对应证据链复验（BE-L3 → 后端守护测试 + ADR-102 触发条件；
  图标 curated → `gen-icon-subset.mjs --report` 复测 chunk 体积；主色 → axe 对比度门禁 + 双平台视觉基线重录）。
